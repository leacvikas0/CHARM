# Validation

The public tests cover:

- Local/world FK roundtrips with non-topological joint ordering.
- A different clip length, fps and bone naming scheme.
- Meter/centimeter equivalence of generated timing maps.
- Monotone source maps, exact anchor preservation, zero-strength identity and edit locality.
- Protected local/world transforms and rotation caps.
- Motion fingerprint normalization and wrong-motion event rejection.
- Invalid inputs, unreviewed config rejection, original/twos without hand roles, and no-overwrite CLI behavior.

The procedural demo additionally checks that pure-timing outputs are exact source-pose samples. Its 180-frame, 30-fps motion and rig are generated by `examples/synthetic/generate.py`. Gesture events describe a designed synthetic accent, not verified real-world contact.

```bash
python -m unittest discover -s tests
python scripts/demo.py --output runs/check_new
```

The preview is reproducible with optional Pillow:

```bash
python -m pip install -e '.[preview]'
python scripts/generate_preview.py --run runs/check_new
```

Numerical tests cannot establish artistic preference, contact realism, collision clearance or arbitrary character skinning. Blender adapters need actual-scene replay verification; the pure Python suite does not certify every Blender rig. Automatic anchors and video-model proposals need review on each new action. No benchmark or universal quality improvement is claimed.
